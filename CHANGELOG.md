# Changelog

## 1.0.0

- Session management for .NET MAUI on iOS and Android
- Access and refresh tokens with rotating refresh and reuse detection
- Automatic access-token refresh and HTTP 401 retry
- Logout for this device or every device
- Absolute session lifetime and idle timeout
- Multi-device session list and revoke
- Biometric unlock (Android BiometricPrompt, iOS LocalAuthentication)
- Secure persistence through Plugin.Maui.SecureStoragePlus
